# Project: Code2LinkedIn — Automated LeetCode-to-LinkedIn AI Agent

Act as a senior Python backend engineer, Chrome Extension developer, and AI integration architect.

Build a production-minded tool that detects my LeetCode submissions, analyzes my actual submitted source code using the Grok API from xAI, captures a screenshot of the Accepted result, and prepares or publishes a professional LinkedIn post with the screenshot attached.

Do not just explain the architecture. Implement the project step by step with complete, runnable code.

## 1. Technology Stack

- Browser extension: JavaScript, Chrome Extension Manifest V3
- Backend: Python 3.11+ and FastAPI
- AI: xAI Grok API using the official API documentation and a configurable model
- Image hosting: Cloudinary Python SDK
- Database: MongoDB with PyMongo
- HTTP requests: HTTPX
- LinkedIn: Official LinkedIn Posts API, OAuth 2.0, and image upload API
- Testing: Pytest

## 2. End-to-End Workflow

1. I open LeetCode and submit a solution.
2. The Chrome extension detects the submission and waits for the final verdict.
3. Only process submissions whose status is Accepted by default.
4. Extract the actual submitted code, programming language, problem title, problem URL, difficulty if available, submission ID, runtime, and memory usage when available.
5. Verify that the extracted code belongs to the exact submission rather than merely reading the current editor contents.
6. Capture a screenshot of the relevant LeetCode page showing the Accepted result. Make the screenshot configurable so that I can choose between the result view and the code editor view.
7. Send the actual source code and available problem metadata to Grok.
8. Ask Grok to produce a structured analysis of the algorithm, approach, data structures, time complexity, space complexity, and a concise learning takeaway.
9. Validate the generated analysis. Never invent complexity values or claim that code was accepted unless the submission result confirms it.
10. Upload the screenshot to Cloudinary.
11. Generate a professional LinkedIn caption with relevant hashtags.
12. Display a preview containing the screenshot and caption.
13. In approval mode, publish only after I explicitly approve the post.
14. Publish through the official LinkedIn API after valid OAuth authorization and successful permission checks.
15. Save the submission ID, AI analysis, image reference, caption, LinkedIn post ID, and publication status in MongoDB.

## 4. Grok API Integration

Use the official xAI API documentation:
https://docs.x.ai/

Read the current API documentation before implementing requests. Use an environment variable for the API key and a configurable model name.

Request a structured response containing:
- Problem title
- Problem summary
- Algorithmic approach
- Step-by-step explanation
- Data structures used
- Time complexity and reasoning
- Space complexity and reasoning
- Important edge cases
- Short professional LinkedIn caption
- Relevant hashtags

Analyze the actual source code. Do not infer that an algorithm is optimal or assign complexity values without reasoning from the implementation.

Validate the response using Pydantic. Handle API failures, invalid output, rate limits, and unavailable model access gracefully.

Do not assume that the xAI API has a free tier. Explain how to verify account credits, current pricing, and rate limits.
